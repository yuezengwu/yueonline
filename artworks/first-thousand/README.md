## 开发

`pnpm dev:first-thousand` 启动该作品。`pnpm test:first-thousand` 验证原有账号顺序与坐标、无限铺排和唯一全景、11 种视口的全景边界、曲面命中与裁剪、完整搜索、名单校验和显卡纹理尺寸选择。`pnpm check` 执行这些 JS 测试、代码检查和整站构建。

修改图集生成工具时另外运行 `pnpm test:first-thousand:prepare`（Python 3 + Pillow）：使用离线色块验证三档图集的真实像素与账号索引、部分高清下载回退、保留旧账号、失败不覆盖旧名单；部署构建无需 Python。

`python3 artworks/first-thousand/tools/prepare-portraits.py <已核对素材目录>` 从 `manifest.json`、`downloads.json` 和可选的 `hires-downloads.json` 生成三档图集，依赖 Pillow。部分高清下载缺失时回退普通下载；缺失的实际头像文件会明确报错。输入必须保留既有账号顺序，再追加新账号；新增记录可标注 `avatarStatus` 为 `profile`、`default` 或 `unavailable`。生产生成强制检查原 995 位的完整顺序，并阻止移除输出目录中已有的新账号。先写完哈希图集，最后原子替换名单，避免名单指向半成品。`--output <目录>` 可生成到独立验收目录；`--preview` 仅用于少量实验素材，不能用于生产发布检查。当前布局最多 2,240 个唯一账号；超限会明确失败，需要先扩展布局，不能静默截断。
